# Setup & Deployment Instructions

1. **Create your repository:** On GitHub, create a new repository named exactly your username: `Fayaz-Codify/Fayaz-Codify`. Ensure it is set to **Public** and check **Add a README file**.
2. **Upload files:** 
   - Upload `README.md` to the root of your repository.
   - Upload the `assets/` folder containing all image and SVG files (`id.png`, `right_pointing.png`, `hero.svg`, `about-life.svg`, `stack.svg`, `id-dashboard.svg`, `connect.svg`).
3. **Commit & View:** Commit your changes to the default branch and visit `https://github.com/Fayaz-Codify` to see your live animated profile!
