# Third-party assets

## Fonts (embedded as subset base64 WOFF2 in every SVG)
- **Bebas Neue**, Copyright 2010 Dharma Type. SIL Open Font License 1.1. Source: github.com/google/fonts (ofl/bebasneue). License: `OFL-BebasNeue.txt`.
- **JetBrains Mono** (Medium 500 instance), Copyright JetBrains. SIL Open Font License 1.1. Source: github.com/google/fonts (ofl/jetbrainsmono). License: `OFL-JetBrainsMono.txt`.
Both were subset to Basic Latin plus a few punctuation marks. The OFL permits this; the font names are kept as in the originals.

## Icons
- Brand marks for PHP, Laravel, MySQL, JavaScript, React, Python, Tailwind CSS, Inertia.js, Git, WordPress, GitHub and LinkedIn come from **Simple Icons v13.21.0** (npm `simple-icons`), licensed CC0 1.0 (`CC0-simple-icons.md`). Source: https://simpleicons.org. (Newer Simple Icons releases dropped LinkedIn, so v13.21.0 was pinned.)
- The brand names and logos remain trademarks of their owners; they are used here only to label technologies and profiles.
- PHP, MySQL, Python and WordPress marks are tinted slightly lighter than their official hex values so they stay legible on the navy background.
- **REST APIs** has no brand mark. It uses a generic "</>" style glyph drawn for this project (no external source).

## Portraits
- `id.png` and `right_pointing.png` are your stylized portraits. The checkerboard was removed with an automated border flood-fill; the alpha cut-outs are in `source/`. The SVGs embed downscaled, palette-quantized copies.
